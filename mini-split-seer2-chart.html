What this table is

The dataset view is every certified model with product type "HP - Mini or Multi Split". It does not label single-zone versus multi-split. This page keeps 17 combinations:

  • Daikin OTERRA outdoor models that start with RXF. Daikin’s OTERRA wall-mount page calls that family a single-zone heat pump.
  • Mitsubishi Electric MUZ-FS models whose outdoor number does not contain NAH. Mitsubishi’s MUZ-FS page calls it a wall-mounted single-zone heat pump.
  • MRCOOL DIY wall pairs named in the 5th Gen DIY Single Zone Series brochure (version date on the PDF: 06.24.26) that were also in the dataset that day.

The figures are copied from ENERGY STAR. The Dataset markup on this page names a Creative Commons Attribution license for this page’s table and CSV.

Cooling capacity, SEER2, EER2, and HSPF2 are the dataset fields cooling_capacity_btu_h, seer2_btu_wh, eer2_btu_wh, and hspf2_btu_wh, copied as published. The dataset response on October 6, 2026 carried Last-Modified: Mon, 05 Oct 2026 16:15:09 GMT. Asterisks in a model number are part of the published model string. Click a heading to sort. The first order is brand, then cooling capacity.

The same MRCOOL brochure lists DIY-36-HP-C-230D25-O. That outdoor model was not in this dataset on the access date, so it has no row here.

Use it with this calculator

The table is a nameplate. The calculator is a room. They answer different questions. One pass through this site’s room-load function, stated inputs: 200 square feet, 8 ft ceiling, 2 windows, average sun (factor 1.00), average insulation (factor 1.00).

Shell = 200 × 25 × (8 ÷ 8) × 1.00 × 1.00 = 5,000 BTU/hr. Windows = 2 × 600 = 1,200. Subtotal = 6,200. Raw load = 6,200 × 1.10 = 6,820 BTU/hr. Rounded up to the next 500, the planning result is 7,000 BTU/hr. This calculator’s mini-split list then picks 9,000 BTU/hr, the smallest head at or above 7,000.

A row in the table whose cooling capacity is 6000 Btu/h is below that planning result. A row whose cooling capacity is 9000 Btu/h uses the same integer as the head the calculator picks. That is not a reason to buy one model. SEER2 is not an input to the room-load function. Run the calculator for the room, then read a nameplate here if you want the certified ratings.

Frequently asked questions

Where do the cooling capacity, SEER2, EER2, and HSPF2 figures come from?

Each figure is copied from the ENERGY STAR Certified Mini-Split Heat Pumps dataset (akti-mt5s) as accessed on October 6, 2026. The record link in the row opens that combination. If a field were blank in the dataset, the cell would say not listed. None of the rows in this table had a blank in those four fields.

Does SEER2 change this calculator's BTU result?

No. The room-load function does not take SEER2, EER2, or HSPF2 as an input. Those ratings describe the certified combination. The calculator describes the room.
